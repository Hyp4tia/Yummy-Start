# Yummy Learning

Optional companion to the Yummy foundation skill. Use during later authorized
project work when the user gives feedback whose scope or duration matters. This
skill does not alter Yummy setup: `/yummy` remains create-only and preserves all
existing project files.

## Procedure

1. Read the applicable project instructions and [the learning guide](references/learning.md).
2. Apply direct user corrections to the current work immediately.
3. Keep task-specific or unclear feedback local to the current task. Persist only
   direct user instructions with clear lasting scope.
4. Make the smallest change needed in the actual project, within the user's
   authorized scope. Never save credentials or broaden a project rule globally.
5. Re-read the changed entry and confirm its scope. Tell the user what was saved,
   or say plainly when it was not saved.
